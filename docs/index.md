# finalproject

BST260 Final Project — Fall 2026

## Project Overview

This project investigates geographic and temporal patterns in homicide
and firearm mortality in the United States using publicly available CDC
datasets.

The project includes reproducible analyses, statistical visualizations,
and documentation of findings and limitations.

## Datasets

1.  CDC Homicide Mortality (`cdcmurd`)
2.  CDC Firearm Mortality (`cdcfiremort`)
